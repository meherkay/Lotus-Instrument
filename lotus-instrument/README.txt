LOTUS — Option A: Make an Instrument

HOW TO RUN
1. Unzip the project.
2. Open index.html in a browser with internet access (p5.js loads from CDN).
3. Click the page once, then press A S D F G H J, or click a lotus.
4. Browser sound starts only after user interaction.

P5 WEB EDITOR
Create a new sketch. Replace index.html with the included index.html, sketch.js with the included sketch.js, and style.css with the included style.css. Do not paste HTML into sketch.js.

GITHUB PAGES
Upload index.html, sketch.js and style.css to the ROOT of your GitHub repository (not inside the lotus-instrument folder). In Settings > Pages choose Deploy from branch, main, / (root).

Sound uses the browser Web Audio API; p5.js is used for graphics, events, and animation. The console logs each triggered note.
